# Configs
Owner: Devam Patel (Security, Documentation and Diagram Lead)

A saved copy of every device's settings, one text file per device, taken with `show running-config`.
Example name: `R_CORE_01.txt`

We save new copies after every gate from Week 3 on, so you can see how the network grew.
Any line that is not obvious gets a short note explaining why it is there.
